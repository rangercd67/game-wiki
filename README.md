## 来源说明

本仓库由 [`jcwiki`](https://github.com/rangercd67/jcwiki) 拆分而来（2026-09-23）。
原仓库在 `840b2988` 一次提交里把游戏百科并入了产线计算器项目，导致一个 50MB 的游戏资料目录
和一个小型前端工具挤在同一仓库里、主题与体积都不匹配。本次拆分**保留了原有的提交历史**
（用 `git filter-repo` 抽取路径，未压缩历史）。

拆分后：

- 本仓库 —— 纯游戏资料静态页
- [`jcwiki`](https://github.com/rangercd67/jcwiki) —— 只留「江城创业记 · 产线计算器」这个前端工具

## 本地预览

纯静态站点，直接起一个静态服务器即可（不要用 `file://` 打开，中文路径与相对引用容易出问题）：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080/多娜多娜/
```
