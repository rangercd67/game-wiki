游戏内共有 **6 个等级的武器**，同一等级还会分成若干「型」（P 型偏力量、T 型偏技巧、
无后缀为均衡型）。下表把 10 名可操作角色的每一把武器逐条列出，含价格与三项数值。

## 读表要点

- `TOTAL` 恒等于 `POW + TEC`，即同一把武器的总数值。这也是本站转写时的自校验条件，
  122 行全部通过。
- **LV6 武器是二周目地图掉落，一周目无法获取。**
- **空白格 = 原表该格没有填写，不是 0。** 阿熊 / 梅蒂可 / 绮菈绮菈 / 珀儿诺 / 虎太郎 /
  扎帕 的 LV1 只有武器名、没有数值；安缇娜、菊千代、爱丽丝、小丑 在原表中整行空白
  （菊千代与爱丽丝连 LV2 也空白），这些空行未录入。
- 同档位武器的价格并不相同，个别明显偏低：虎太郎「宝版特制饿狼」19600（同档另两把 28000）、
  扎帕「A战术性EZ」179200 与「A战戈术↑生」102400（同档另一把 256000）、
  小丑「金属贝比」59500（同档另两把 85000）。均按原表照录，未作调整。
- 数值分布有规律：`LV2 总 380 → LV3 1140/1080 → LV4 3420/3240/3060 → LV5 10260/9720/9180
  → LV6 30780/29160/27540`。同一等级里，**总数值最高的那一型通常是均衡型**，
  偏低的两型分别把数值挪向力量或技巧。

## 属性作用

以下是原图对各项属性的说明（[武器系统与选型](/dohna/weapons/) 已讲过 POW / TEC 的
取舍结论，这里补上原文对 SPD / MP / VP 与「加速起步」的机制描述）：

| 项 | 作用 |
| --- | --- |
| 力量 POW | 影响主动技能的伤害 |
| 技巧 TEC | 影响暴击率、施加 debuff 的成功率、被动技能、战斗开始「加速起步」的成功率 |
| 速度 SPD | 影响行动顺序 |
| MP | 即「蓝量」。蓝量耗尽后伤害会锐减；透支蓝量会降低属性值——**-40% 时 SPD 大幅减少，-70% 时 TEC 与 SPD 大幅减少，-100% 时 POW / TEC / SPD 均大幅减少** |
| VP | 即「怒气」。造成或承受伤害时积攒，影响部分主动技能的威力；满怒时可以使用怒气技能 |

**加速起步**：战斗中敌我双方速度（SPD）越高，行动顺序一般越靠前；但仅限发生加速起步的
**第 1 回合**，引起加速起步一方的行动顺序会更容易提前。当敌我双方前锋**总体技巧（TEC）
差距较大**时，便有可能发生加速起步。
