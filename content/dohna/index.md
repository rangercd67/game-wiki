《多娜多娜 一起做坏事吧》（ドーナドーナ 一緒に悪い事をしよう / Dohna Dohna，也译作「一起来干坏事吧」）
是 AliceSoft 开发的 RPG，玩法由两条线交替构成：**迷宫战斗**与**据点经营**。

本站只收录游玩所需的系统与数值资料（角色、武器、章节分支、地图掉落），
**不收录成人内容**。关于 18 禁内容请自行查阅官方说明。

## 资料缺口（尚未收录）

以下条目在公开来源中只有标题、没有可用数据，或者虽已拿到原图但尚未逐格核对，
因此**本站暂不提供**——写入未经核实或估算的数值比留空更糟：

- 武器掉落**逐点明细**的表格化（原表已作为图片收录在
  [掉落明细与掉落率](/dohna/drop-details/)，400 余行逐格核对后再转成可筛选的数据表）
- 武器强化的素材与所需金额
- 词条的**官方原文数值**：现有 63 条来自玩家自制的中译表，且原帖未说明表内两套数值
  （`LKS / TEC / MEN` 与 `LKS修正 / TEC修正 / MEN修正`）的区别
- 据点设施（设备 / 仓库 / 派遣）的解锁条件与效果数值
- 敌人属性与弱点表
