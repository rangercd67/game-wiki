### 执行后审计抓出 1 个真实误删（关键教训）
`HKLM\…\Uninstall\Steam App 3288260`（黑神话：悟空 游戏音乐精选集）被误删。
它被判「失效」只因 `UninstallString` 指 `D:\steam\steam.exe`（Steam 搬到 `D:\Applications\Steam`），
**但游戏明明装着**：`E:\Games\GameLibrary\SteamLibrary\steamapps\appmanifest_3288260.acf`
与 `steamapps\music\Black Myth Wukong Soundtrack Selection` 都在。
→ 已从备份还原，并顺手把 `UninstallString`/`InstallLocation`/`DisplayIcon` 改成新路径。
**教训：「引用的 exe 不存在」≠「应用没了」。** 游戏/启动器类必须查 manifest
（`libraryfolders.vdf` 里**全部**库路径都要查）。已写入技能。

### 环境坑（本机实测）
- **`sc.exe` 也被沙箱程序黑名单拦**（`reg.exe` 之外）。后果：不能 `sc delete/config`；
  服务类动作只能改注册表 `ImagePath`。C 类死链服务（`EpicGamesUpdater`、`phpStudySrv`）
  **未动**——用户确认范围只含 A+B。
- `.reg` 因 `reg.exe` 被拦**无法在沙箱内 import** → 备份必须以 **JSON** 为主
  （`winreg` 可还原），`.reg` 只作沙箱外人工导入用。
- PowerShell 5.1 `Get-Content` 按 ANSI 解码 UTF-8 清单 → 中文键名变 `鍘熺`（原神）被静默跳过。
  执行器改用 Python `winreg`（原生 UTF-8）。
- `$keyObj | Get-ChildItem -Recurse` 不枚举注册表子键；`-LiteralPath <dir> -Recurse -Include` 忽略 `-Include`。
- **自查两次用错判据**：① 按**键名**前缀查 NVIDIA/Edge/Adobe（键名是 GUID，品牌在 `DisplayName`）；
  ② 32 位视图读 MSI 缓存得 0 产品 → 误报 25 条孤儿（MSI 产品库是共享位置，要比 64 位那份）。
