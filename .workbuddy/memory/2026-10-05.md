## 修掉侧边导航顺序 bug（本次的核心改动）

**症状**：侧边导航的顺序与「上一页/下一页」自相矛盾。刚入的 `weapon-prices` 排在
`weapons` 前面；`p5r/palace` 导航从「双叶」打头（应为鸭志田）。

**根因**：`collect_pages()` 里 `pages` 是 `sorted(directory.rglob("*.md"))` 的**文件名序**，
`order` 只被用来对临时 `bucket` 排序（供 prev/next），**从未回写 `pages`**。
而 `_render_nav()` 与首页卡片都直接遍历 `pages` → 导航 = 文件名序。
实测 **13 个多页分组里 9 个** order 序 ≠ 文件名序。

**修复**（`gamewiki/wiki.py`，`collect_pages()` 内 `return` 之前）：
统一用「游戏按 `site.json` 声明序 → 组按 `groups[]` 序 → 组内 `sort_key`（order、缺省靠后）
全局重排 `pages` 本身。这样导航、首页、搜索索引三处口径一致（`p is current` 之类的
身份比较全项目都没有，重排安全）。

**验证**：`nav-order-before/after.txt` diff → 9 组归位；prev/next 与导航逐级咬合
（鸭志田→斑目→金城→双叶→奥村…）；`unittest` 69 tests OK；`checklinks` 86 页 / 8510 引用全有效。

**结论**：`order` 值全部来自 `sources.py` 里显式声明的 `spec.order`（不是自动编号），
所以新顺序就是作者本意。`palace-futaba` 之所以曾排最前，纯属字母序巧合。

### 结论：地图用 waifu2x，**文字表格用 LANCZOS**

- 地图：waifu2x-ncnn-vulkan（`tmp/tools/…-20220728-windows/`），**GPU 可用**

**解析坑**

1. **正文不能非贪婪匹配**：`<div class="content"[^>]*>(.*?)</div>` 会在正文里第一个图片占位 `</div>` 处截断
   （实测只剩 1965 字）。必须按 `<div>`/`</div>` **深度配对**找闭合位（见 `find_content_end()`），恢复后 5779 字。
2. **图片占位有两套写法**，都要换 `[[IMG]]`：`<div class="pb_img_item" data-url='…'>` 与
   `<div data-class="BDE_Image" class="j_media_thumb_holder img_placeholder" data-url='…'>`（外层包 `<span class="wrap pbimgwapper">`）。
3. **`[[IMG]]` 绝不去重**：连续 `<br/><img><br/><img>` 会产出连续标记，去重后「标记数 ≠ 图片数」，
   图片被挤到楼尾（曾 12 楼失配）。修掉后 100 标记 = 100 图，零失配。
4. 楼层 = `<div class="content" lz="1">`；日期取正前方最近的 `<span class="list_item_time">YYYY-MM-DD</span>`。
5. 表情 = `<img src="https://tb2.bdstatic.com/tb/editor/images/face/i_f07.png?t=…">`（纯 emoji，
   与用户名后缀的 `nickemoji` 不是一回事）。
6. UI 噪声文案要清：「看高清大图，打开贴吧App」、回复/赞/收藏/分享/举报。

**单文件 HTML 打包**

- 图片全 base64 内嵌，**JPEG→WebP q90**（实测 21.7 MB 原图 → JPEG q84 5.9 MB → WebP q90 3.0 MB → HTML 4.93 MB）。
- **不要写 `data-full`**：内容 `<img>` 本就是全尺寸，再放一份同图 base64 体积翻倍（曾 9.80 MB）。
  放大层直接用 `src`：`lbImg.src = img.dataset.full || img.src`。
- **Python 模板 `%` 记法**：HTML 里 CSS 的 `width:100%` 会让 `TPL % {...}` 报
  `TypeError: not enough arguments for format string`。改成 `%(name)s`→`{{name}}` 再 `str.replace`，
  且值必须 `str(_v)`。
- 楼层标签先 `re.sub(r'\[\[IMG\]\]|\[\[FACE:[^\]]+\]\]','',line)` 再取首行，否则目录出现 `33楼[[IMG]]`。
