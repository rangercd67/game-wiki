### 两个非直觉发现（已写入技能）

1. **Shell 索引 ≠ 物理占用**：`SHQueryRecycleBin` 报 `size=0.0 MB`，物理上却躺着 4.94 GB
   在 `C:\$Recycle.Bin\S-1-5-18\`（SYSTEM 名下）。**Windows 回收站 UI 只索引当前用户的条目**，
   所以「手动清空回收站」永远清不掉这些 —— 资源管理器里根本看不见。
   剩下的 79.4 MB 是 3 个无 `$I` 的 `$R` 影子目录（Defender ATP 62M / Defender 13.1M / WMP 4.3M），
   属 Windows 保护组件，**不再追**。
2. **`Clear-RecycleBin` 是异步的**：返回（甚至报 `FAILED 系统找不到指定的文件`）之后仍在后台动文件。
   我两次量到 4,941.9 → 2,391.3 MB，一度怀疑「有别的进程在动盘」。**别拿它刚返回时的数字当终态。**

### 意外但有利：`C:\Drivers` 没丢

清空前我想保住这份 2023-02-18 驱动备份（2,550.6 MB），结果**在我动手之前它自己回到了磁盘**：
`C:\Drivers` = 2,125 文件 / 2,550.6 MB，含 Realtek 声卡、Intel 主板·蓝牙·无线、**NVIDIA 驱动 1,894.3 MB**，
目录时间戳仍是 2023-02-18。**我从未执行任何还原命令**（抢救脚本那步 `rescued = False`，
因为它运行时回收站里已无该条目的 `$I`）。是回收站 API 调用过程中的副作用。已如实写进报告。
→ 若用户不要，直接删 `C:\Drivers` 即可（现在回收站对当前用户是通的）。
