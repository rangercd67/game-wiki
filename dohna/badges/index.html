徽章搭配

最近更新于 2026-10-05

徽章是绑在技能槽上的改造件：同一枚技能，挂上不同徽章后效果完全不同 （加伤害、减蓝耗、延长持续回合、加增益效果等）。每名角色有 2 个徽章槽， 随感情等级解锁——所以搭配的核心是「这 2 枚给谁、绑哪个技能」。

下表是一份自用搭配，作者原话是「不敢保证最优解，欢迎交流」。 把它当起点而不是标准答案：徽章要跟着你的队伍分工和当前卡关的地方走。

读表要点

  • A / B / C / D 是四个主动技能槽，徽章绑在哪个槽上就改哪个技能。

「大招」指的是怒气（VP）技能，与 A～D 不是同一个槽。

  • 同一个技能可以叠两枚徽章：例如「C 技能 · 加伤害 ＋ C 技能 · 减蓝耗」，

就是把两个槽都给 C 技能。扎帕与菊千代都是这种「双押同一技能」的写法。

  • 「双加速」「双加血」 是两枚同效果徽章叠在一起。
  • 有两位需要准备两套：
    • 安缇娜：推图用 B 技能那套，进 boss 战前换成 D 技能那套（延长一回合 + 加增益效果）；
    • 爱丽丝：推图可以不带，遇到站位极远的 boss 再换扎帕那一套，或换加血保命。
  • 虎太郎那枚是绑定关系：他的技能本来只持续一回合，没这枚徽章等于没有，

而 boss 战前这枚还要移给安缇娜——用他之前先想好这两枚的分配。

两条实测结论

  • 回血与回蓝技能不吃徽章加成。 这是梅蒂可那一行的关键：加血 / 加蓝类技能挂徽章

提升不了效果，所以她的两个槽直接堆加血更实在（配合被动回血可以当肉）。

  • boss 战的距离问题决定了两处特殊搭配：阿熊开 D 在刷图时不划算，

但 boss 战够不到距离时他就是加攻工具人；爱丽丝作为狙击位，远距离 boss 反而吃得上。
