# Game Wiki 项目规则

## 工作区与数据边界

- 仅在 `D:\Development\Projects\game-wiki` 中创建或修改项目文件。
- `E:\Games\GameTools` 是外部数据来源，默认只读；不得修改、移动或删除其中的内容。
- 不得把 `GameTools` 的完整副本、私有数据或大型生成物提交到本仓库。需要使用的数据应通过明确的导入脚本、配置项或脱敏样例接入。

## 开发方式

- 将任务拆成可验证、可回滚的小步；避免一次混入无关改动。
- 修改前检查现有实现与未提交变更，保留用户已有工作。
- 每个稳定节点应通过相关检查后提交，提交信息准确描述单一目的。
- 复杂任务可交给 Codex 实现或独立审查；审查与实现结论应有可复现依据。

## 安全与隐私

- 不提交密码、令牌、私钥、个人信息、内部地址或受限制的游戏数据。
- 示例配置只保留占位符；共享日志、代码和数据前先脱敏。
- 若发现疑似敏感内容，停止暂存或提交，并先报告具体文件与风险。

## 测试与文档

- 对行为变更补充相称的测试或验证步骤。
- DSH 仅在项目成熟后于独立 Git worktree 中测试，避免污染主工作区。
- 由 WorkBuddy 维护文档、周报和知识库时，以仓库内已验证事实和提交历史为准。
