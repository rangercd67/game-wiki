BGG 排行榜 Top 100

最近更新于 2026-10-05

BoardGameGeek（BGG） 的排行榜是桌游圈事实上的标准榜单：任何一款收录在库里的游戏， 只要有足够多的玩家给它打分，就会被汇总出一个名次。下面这张表是 2026-10-05 的快照， 按 BGG 的 Overall Rank 从第 1 名排到第 100 名。

表头带筛选框，可以直接搜游戏名或年份。「平均分」与「贝叶斯均分」是两个不同的数， 排序用的是后者，两者的区别见怎么读 BGG 排行榜。

为什么只有 100 条

榜单本身有 31,409 条有名字的条目。本页只取前 100，是因为 100 名之后的分数差距 已经很小（整段贝叶斯均分只差约 0.8 分），逐名次解读意义不大。若需要更靠后的名次， 可用页面底部的官网入口自查——BGG 的排行页支持按名次翻页。

内容出处

名次、评分、票数均来自 BoardGameGeek 官方排行榜（boardgamegeek.com/browse/boardgame）， 快照日期 2026-10-05。

取数通道说明：BGG 主站对程序化请求返回 Cloudflare 挑战页（Just a moment...）， 用本机代理直连官网排行页与 XML API 均被拦（HTTP 403 / 401）。本快照取自每日抓取 并同步 BGG 官方排名的公开镜像仓库 beefsack/bgg-ranking-historicals， 取其 2026-10-05.csv，字段为 ID, Name, Year, Rank, Average, Bayes average, Users rated, URL, Thumbnail， 与官网排行页显示的口径一致。未做任何数值改写，仅把票数加上千分位、把分数统一到两位小数。

名次会天天变。本页是某一天的切片，不代表长期格局；同一款游戏在不同日期的名次 可能相差几位。引用时请注明快照日期。
